# Adhan audio — sources and licences

These files are derived from recordings on Wikimedia Commons and from
Creative Commons videos on YouTube (see below). Each file keeps
the licence of its source recording. The MIT licence in the repository root
does **not** apply to them.

Changes made to every file (2026-11-07, Seccadem): audio track extracted from
the source WebM video (Opus), loudness-normalised (EBU R128, -16 LUFS), short
fade-in/fade-out added, down-mixed to mono and re-encoded as MP3 (96 kbps,
44.1 kHz). Metadata stripped. `konya_vandervaart_ccby3.mp3` was also trimmed
at 58.2 s (trailing silence removed). No other edits.
